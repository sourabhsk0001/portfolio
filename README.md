## 📌 Overview

This repository hosts the source code for my personal developer portfolio, designed with an emphasis on **AI Engineering**, clear communication, and interactive technical exploration.

The website is structured into 4 dedicated sections:
1. **Landing Page:** An approachable, less-jargon introduction to who I am, my philosophy on AI engineering, and quick stats.
2. **Projects Page:** High-level project summaries with **centered pop-up exploration panels** detailing problems solved, technical architectures, and code repositories.
3. **Life & Journey Page:** Comprehensive details covering my career north star in AI Engineering, education at KIIT, industry traineeships (SAIL & CCL), verified certifications with direct verification links, and personal hobbies.
4. **Contact Page:** An interactive contact form connected directly to a Formspree endpoint, direct resume download options, and personal contact links.

## 💻 Local Development

### 1. Clone the repository
```bash
git clone https://github.com/sourabhsk0001/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
The static assets will be compiled into the `dist/` directory with relative base paths (`./`) optimized for GitHub Pages.

## 🌐 Deploying to GitHub Pages

This repository includes a preconfigured GitHub Actions workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

### Enabling GitHub Pages on your repository:
1. Go to your repository on GitHub: `https://github.com/sourabhsk0001/portfolio`
2. Navigate to **Settings** → **Pages**
3. Under **Build and deployment** → **Source**, select **GitHub Actions**
4. Any push to the `main` branch will automatically trigger the workflow, build the site, and publish it to:
   ```
   https://sourabhsk0001.github.io/portfolio/
   ```
